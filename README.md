# AeK Vitrine

Este projeto consiste em uma aplicação que está sendo desenvolvida para a empresa AeK Vitrine.

## Tecnologias utilizadas 🤖

- React
- Next
- ESLint
- Cypress
- Sass
- Typescript

## Como executar ⚠️

Clone o projeto:

```bash
  git clone git@github.com:Lucas-Almeida-SD/AeK_Vitrine.git
```

Acesse o diretório:

```bash
  cd AeK_Vitrine
```

Instale as dependências do projeto:

```bash
  npm install --force
```

Execute o projeto:

```bash
  npm run dev
```

Abra a aplicação no navegador acessando http://localhost:3000
